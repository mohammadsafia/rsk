## Sections

Split long forms into titled groups. Consecutive sections get a hairline between them.

<Example title="Patient and insurance">
  <div className="w-full max-w-lg">
    <FormSection title="Patient" description="Who the visit is for">
      <Input aria-label="Full name" placeholder="Full name" />
      <Input aria-label="Phone" placeholder="Phone" />
    </FormSection>
    <FormSection title="Insurance">
      <Input aria-label="Policy number" placeholder="Policy number" />
    </FormSection>
  </div>
</Example>

In a real form the children are `Form*` fields inside a [FormContainer](/docs/components/form-container).

Other `<section>` attributes pass through.

## Accessibility

- Renders a `<section>`; the title is a heading, so keep the page's heading levels in order around it.

## RTL notes

- No direction-specific behaviour; the title and description align to the start.
