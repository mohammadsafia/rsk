## Example

The smallest complete form: a `FormContainer` with two fields and a submit button. "Toggle Disabled" disables every field at once.

  <FormBasicDemo />
</Example>

## Steps

1. Create the form with `useForm`, with `defaultValues` and (optionally) a `zodResolver`.
2. Wrap the fields in [FormContainer](/docs/components/form-container) and pass `formContext` and `onSuccess`.
3. Add fields by `name`. Controlled fields such as `FormSelect` also take `control={form.control}`.
4. Add a submit button, or `FormContainer.Actions` for the standard Save / Cancel row.

## Accessibility

- Each field has a real label, and errors are announced through `aria-describedby`.
- Use a `type="submit"` button so Enter submits the form.

## RTL notes

- Fields and labels follow the page direction; the email value is typed left to right because inputs use `dir="auto"`.
