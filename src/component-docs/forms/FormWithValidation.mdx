## Example

Describe the rules once in a zod schema and pass `zodResolver(schema)` to `useForm`. Submit with an incomplete email or a short password to see the messages.

## Writing messages

- Say what to do, not what went wrong: "Enter a complete email address", not "Invalid email".
- Put the messages in the locale files and build the schema inside the component with `t()`, so they translate.
- Use `z.coerce.number()` for number fields, since inputs report strings.

## Accessibility

- Errors appear under each field, set `aria-invalid`, and are linked with `aria-describedby`; focus moves to the first invalid field on submit.

## RTL notes

- Messages align to the start of the field; translated messages read right to left in Arabic.
