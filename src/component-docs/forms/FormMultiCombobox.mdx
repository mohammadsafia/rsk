## Multiple values

The value is an array. Each selection shows as a badge in the field; the list stays open so you can pick several.

## Accessibility

- Keyboard users add and remove values from the open list: Enter on a checked option unchecks it.
- The small ✕ on each badge is a pointer shortcut only; it is not keyboard-focusable.

## RTL notes

- Badges run in reading order; the chevron sits at the end of the field.
