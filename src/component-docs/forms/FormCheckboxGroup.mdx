## Options

The value is an array of the selected option values. Options can be strings or objects; `getOptionLabel` and `getOptionValue` read them.

## Accessibility

- The options sit in a `role="group"` labelled by the field label; each option is a checkbox named by its text.

## RTL notes

- The options wrap in reading order, and each box sits at the inline start of its label.
