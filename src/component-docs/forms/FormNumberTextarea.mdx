## Numbers

`FormNumber` wraps [FormattedNumber](/docs/components/formatted-number) and stores a `number` (or `null`), not a string. It is a controlled field, so pass `control`.

<Example title="Quantity, signed range, notes" code={demoSource('FormNumberTextareaDemo')}>
  <FormNumberTextareaDemo />
</Example>

`min` defaults to `0`. The second field passes `min={-10}` to allow negative values.

## Accessibility

- The label is linked to the number input; the step buttons have translated labels.

## RTL notes

- The field follows the page direction while the number keeps its left-to-right order (`-1,250.50`), with Western digits.
