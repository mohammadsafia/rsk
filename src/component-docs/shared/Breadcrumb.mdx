import { Slash } from 'lucide-react';

## Trail

Items with `href` are links; the last item is the current page.

<Example title="Settings page">
  <Breadcrumb links={[{ title: 'Dashboard', href: '/dashboard' }, { title: 'Settings', href: '/settings' }, { title: 'Profile' }]} />
</Example>

## Root and separator

`withRoot` prepends a translated "Home" link; `separator` replaces the chevron.

<Example title="With root, custom separator">
  <Breadcrumb withRoot separator={<Slash className="size-3" />} links={[{ title: 'Members', href: '/members' }, { title: 'Layla Haddad' }]} />
</Example>

[PageHeader](/docs/components/page-header) renders a breadcrumb above the title for you.

## API

<PropsTable
  rows={[
    { prop: 'links', type: '{ title: string; href?: string }[]', required: true, description: 'The trail, root first.' },

Renders nothing when `links` is empty and `withRoot` is off.

## Accessibility

- A `nav` labelled "Breadcrumb" with an ordered list; the last item has `aria-current="page"`.
- Separators are hidden from screen readers.

## RTL notes

- The trail runs right to left in Arabic and the default chevron mirrors to point along it.
