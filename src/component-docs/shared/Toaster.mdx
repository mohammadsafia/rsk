import { Button } from '@components/ui';
import { useToast } from '@hooks/shared';

export const ToasterDemo = () => {
  const { toast } = useToast();
  return (
    <Button variant="outline" onClick={() => toast({ tone: 'success', title: 'Changes saved', description: 'The patient record was updated.' })}>
      Show a toast
    </Button>
  );
};

## Mount once

The Toaster draws whatever `useToast().toast()` queues. The app layout, the auth layout and this docs layout each mount one, so you rarely add it yourself.

```tsx
function AppLayout() {
  return (
    <>
      <AppShell sidebar={<AppSidebar />}>…</AppShell>
      <Toaster />
    </>
  );
}
```

Toast options (tone, action, position) are on the [Toast](/docs/components/toast) page.

## API

Toaster takes no props. It shows up to the queue limit, closes each toast after 5 seconds, and places the viewport using the newest toast's `position`.

## Accessibility

- The viewport is a labelled region; toasts are announced politely and F8 moves focus to them.

## RTL notes

- Swipe-to-dismiss follows the reading direction (swipe left in Arabic), and the default corner is top-end.
