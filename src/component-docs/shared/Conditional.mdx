## If and else

`Conditional.If` renders its children when `condition` is true; `Conditional.Else` renders when no `If` matched.

<Example title="Branches">
  <div className="grid gap-2 text-sm">
    <Conditional>
      <Conditional.If condition={true}>
        <span className="text-success">Insurance verified</span>
      </Conditional.If>
      <Conditional.Else>
        <span className="text-danger">Insurance missing</span>
      </Conditional.Else>
    </Conditional>
    <Conditional>
      <Conditional.If condition={false}>
        <span>Hidden</span>
      </Conditional.If>
      <Conditional.Else>
        <span className="text-fg-muted">No upcoming visits</span>
      </Conditional.Else>
    </Conditional>
  </div>
</Example>

## Alone

`Conditional.If` also works on its own, as a readable `condition && …`.

```tsx
<Conditional.If condition={isAdmin}>
  <Button tone="danger">Delete</Button>
</Conditional.If>
```
