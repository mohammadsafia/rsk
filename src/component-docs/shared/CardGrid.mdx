## Imports

```tsx
import { CardGrid } from '@components/shared';
```

## Code

```tsx
// Default: 1 column, 2 from sm, 4 from lg
<CardGrid>
  <Card>…</Card>
</CardGrid>

<CardGrid columns={2} gap="lg">…</CardGrid>

<CardGrid columns={{ base: 1, md: 2, xl: 3 }}>…</CardGrid>
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `columns` | `1–6 \| { base?, sm?, md?, lg?, xl? }` | `{ base: 1, sm: 2, lg: 4 }` | A number fixes the count; an object sets it per breakpoint. |
| `gap` | `'sm' \| 'md' \| 'lg'` | `'md'` | 8, 16 or 24 px. |
