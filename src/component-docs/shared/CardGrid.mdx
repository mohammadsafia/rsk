## Fixed and per-breakpoint columns

A number fixes the count; an object sets it per breakpoint.

<Example title="Two columns, large gap">
  <CardGrid columns={2} gap="lg" className="w-full">
    <Card title="Morning shift" description="08:00 – 14:00" />
    <Card title="Evening shift" description="14:00 – 20:00" />
  </CardGrid>
</Example>

```tsx
<CardGrid columns={{ base: 1, md: 2, xl: 3 }}>…</CardGrid>
```

## Accessibility

- A plain grid `div`; cards keep their own headings, so the reading order is the source order.

## RTL notes

- Cards flow right to left in Arabic; wrap numbers in `dir="ltr"` as above.
