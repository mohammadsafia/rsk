## Plain

The default: the extension's icon in the muted token, for list rows and secondary surfaces.

<Example title="Plain icons">
  <FileIcon extension="pdf" />
  <FileIcon extension="docx" />
  <FileIcon extension="xlsx" />
  <FileIcon extension="png" />
  <FileIcon extension="mp4" />
  <FileIcon extension="mp3" />
  <FileIcon extension="pptx" />
  <FileIcon extension="zip" />
</Example>

## Chip

`variant="chip"` adds a tinted background and the uppercase extension, as in file-card headers.

<Example title="Chips">
  <FileIcon extension="pdf" variant="chip" />
  <FileIcon extension="docx" variant="chip" />
  <FileIcon extension="xlsx" variant="chip" />
  <FileIcon extension="csv" variant="chip" />
  <FileIcon extension="png" variant="chip" />
  <FileIcon extension="mp4" variant="chip" />
</Example>

## Sizes

`size` sets the glyph in pixels; the chip's padding stays constant.

<Example title="16 to 32px">
  <FileIcon extension="pdf" size={16} />
  <FileIcon extension="pdf" size={24} />
  <FileIcon extension="pdf" size={32} />
  <FileIcon extension="docx" variant="chip" size={16} />
  <FileIcon extension="docx" variant="chip" size={24} />
  <FileIcon extension="docx" variant="chip" size={32} />
</Example>

## Normalisation and fallback

Dotted, undotted and any-case extensions all work. Unknown or missing extensions fall back to a generic file icon, and the chip drops its label.

<Example title="Accepted inputs">
  <FileIcon extension=".pdf" variant="chip" />
  <FileIcon extension="PDF" variant="chip" />
  <FileIcon extension="Docx" variant="chip" />
  <FileIcon extension="zip" variant="chip" />
  <FileIcon extension={null} variant="chip" />
</Example>

## Supported extensions

| Group | Extensions | Icon |
|---|---|---|
| Document | `pdf`, `doc`, `docx`, `txt` | `FileText` |
| Spreadsheet | `csv`, `xls`, `xlsx` | `FileSpreadsheet` |
| Presentation | `ppt`, `pptx` | `File` |
| Image | `jpg`, `jpeg`, `png`, `gif` | `FileImage` |
| Audio | `mp3`, `wav`, `ogg`, `webm` | `FileAudio` |
| Video | `mp4`, `avi`, `mov`, `mkv` | `FileVideo` |
| Unknown | anything else, `null`, `undefined` | `File` |

The `FileExtension` union type is exported for narrowing at call sites.

Other `<span>` attributes pass through.

## Accessibility

- The glyph has no text alternative, so always show it next to the file name; the chip's extension label is real text.
- If an icon stands alone, pass `aria-label` (or `role="img"` with a label) on the span.

## RTL notes

- No direction-specific behaviour; extension labels are Latin and never mirror.
