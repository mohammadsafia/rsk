  const [status, setStatus] = useState(STATUS_OPTIONS[0]);
  const [assignee, setAssignee] = useState(ASSIGNEE_OPTIONS[0]);
  return (
    <FileCard className="max-w-md" entry={PARTY_NOTICE} accessors={ACCESSORS}>
      <FileCard.Header>
        <FileCard.Title />

        <FileCard.Actions>
          {(entry) => (
            <>

      <FileCard.Preview>{(entry) => <FileCard.FileShape />}</FileCard.Preview>

## Composition

Actions, approve and reject accept `condition` and `permissions` (they are composed with `withConditional` and `withAuth`), so the card hides what the user can't do:

```tsx
<FileCard.Item condition={entry.canDelete} permissions={[Permissions.Delete]} tone="danger" onClick={onDelete}>
  <Trash />
  Delete
</FileCard.Item>
```

| Part | Kind | Renders |
|---|---|---|
| `Header` · `Footer` | container | — |
| `Title` | reads context | file-icon chip and title |
| `Actions` | render-prop children | dropdown trigger and menu |
| `Item` · `Separator` | `DropdownMenu` parts | conditional, permission-aware items |
| `Preview` | render-prop children | the preview region |
| `FileShape` · `FolderShape` | visual | document watermark, or folder with `count` |
| `StatusPill` | `Badge` | soft status badge |
| `ApprovalPrompt` · `Approve` · `Reject` | visual · buttons | approval copy and actions |
| `Status` · `Assignee` | baked combobox | `options`, `getOption*`, `value`, `onChange` (sync or async) |
| `Date` | reads context | date from `accessors.getDate` |

## Accessibility

- The card is an `article` titled by its file name; the actions menu trigger is a labelled icon button.
- With `onClick`, the card is keyboard-activatable; keep the menu and pickers as separate tab stops.

## RTL notes

- The file chip and title sit at the start, the actions menu at the end; the due date is formatted for the app language with Western digits.
