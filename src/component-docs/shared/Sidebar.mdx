## Code

```tsx

  <Sidebar.Header>
    <Logo />
    <Sidebar.CollapseButton />
  </Sidebar.Header>
  <Sidebar.Content>
    <Sidebar.Group label="Clinic">
      <Sidebar.Item href="/schedule" icon={CalendarDays} active>Schedule</Sidebar.Item>
      <Sidebar.Item href="/patients" icon={Users} badge={4}>Patients</Sidebar.Item>
    </Sidebar.Group>
  </Sidebar.Content>
  <Sidebar.Footer>…</Sidebar.Footer>
</Sidebar>
```

## API

| Part | Props | Notes |
|---|---|---|
| `Sidebar` | `collapsed?` | Defaults to the surrounding `AppShell`'s state. Collapsed styles apply from `md` up. |
| `Sidebar.Group` | `label` | Labels the group (`role="group"`); hidden visually when collapsed. |
| `Sidebar.Item` | `href`, `icon`, `active?`, `badge?` | Active items get `aria-current="page"` and the hover tint — never a side stripe. Collapsed items show a tooltip. |
| `Sidebar.SubMenu` | `icon`, `label`, `active?` | Clicking it while collapsed expands the sidebar first. |
| `Sidebar.CollapseButton` | — | Desktop only; toggles and remembers the collapsed state. |
