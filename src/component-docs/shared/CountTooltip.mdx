## Default

Show the first item, then a `+N` chip whose tooltip lists the rest.

<Example title="Care team">
  <div className="flex items-center gap-2 text-sm">
    <span>Dr. Layla Haddad</span>
    <CountTooltip count={3}>
      <CountTooltip.Trigger />
      <CountTooltip.Item icon={<User size={14} />}>Dr. Omar Khalil</CountTooltip.Item>
      <CountTooltip.Item icon={<User size={14} />}>Dr. Sara Odeh</CountTooltip.Item>
      <CountTooltip.Item icon={<User size={14} />}>Nurse Rana Saleh</CountTooltip.Item>
    </CountTooltip>
  </div>
</Example>

## Custom trigger

Pass children to `CountTooltip.Trigger` to change its text, or skip it: the first child then becomes the trigger.

<Example title="Text and element triggers">
  <div className="flex flex-wrap items-center gap-6 text-sm">
    <span className="flex items-center gap-2">
      Documents
      <CountTooltip count={2}>
        <CountTooltip.Trigger>View all</CountTooltip.Trigger>
        <CountTooltip.Item icon={<FileText size={14} />}>referral.pdf</CountTooltip.Item>
        <CountTooltip.Item icon={<FileText size={14} />}>lab-results.pdf</CountTooltip.Item>
      </CountTooltip>
    </span>
    <span className="flex items-center gap-2">
      x-ray-front.png
      <CountTooltip count={2}>
        <Button variant="ghost" size="sm">+2 files</Button>
        <CountTooltip.Item icon={<FileText size={14} />}>x-ray-side.png</CountTooltip.Item>
        <CountTooltip.Item icon={<FileText size={14} />}>x-ray-back.png</CountTooltip.Item>
      </CountTooltip>
    </span>
  </div>
</Example>

Tooltip props such as `side` and `align` pass through.

## Accessibility

- The tooltip opens on hover and keyboard focus. Make sure the trigger is focusable: the default chip is, and a custom trigger should be a button.
- Tooltips can't be reached on touch screens, so don't hide information that's needed only there.

## RTL notes

- The chip follows the item it belongs to, and item icons sit at the start of each line.
