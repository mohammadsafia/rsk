## Accessibility

- The mark is `role="img"` named "RSK"; the lockup's wordmark is text, so screen readers read it once.
- When the logo is a home link, give the link the label ("RSK home") rather than the image.

## RTL notes

- The lockup keeps the mark at the start, so it sits to the right of the wordmark in Arabic; the Latin wordmark never mirrors.
