## Code

```tsx
<Logo />                               // mark, 24px
<Logo size="sm" />                     // 16px geometry
<Logo variant="lockup" size="lg" tagline />
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `variant` | `'mark' \| 'lockup'` | `'mark'` | The mark is `role="img"` named "RSK"; the lockup shows the wordmark as text. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 16, 24 or 32 px. `sm` uses larger squares so they survive rasterising. |
| `tagline` | `boolean` | `false` | Lockup only: adds "React Starter Kit". |

The accent square is the only accent on a surface that shows the logo — never place it on an accent background.
