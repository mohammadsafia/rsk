## Imports

```tsx
import { DescriptionList } from '@components/shared';
```

## Code

```tsx
<DescriptionList
  columns={2}
  items={[
    { term: 'Full name', value: 'Sara Haddad' },
    { term: 'File number', value: 'MRN-20391', numeric: true },
    { term: 'Mobile', value: null }, // renders "—"
  ]}
/>

<DescriptionList layout="inline">
  <DescriptionList.Item term="Doctor" value="Dr. Lina Khoury" />
  <DescriptionList.Item term="Room" value="B-204" numeric />
</DescriptionList>
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `items` | `{ term, value?, numeric? }[]` | — | Or pass `DescriptionList.Item` children. |
| `columns` | `1 \| 2 \| 3` | `1` | Responsive: one column on phones, two from `sm`, three from `lg`. |
| `layout` | `'stacked' \| 'inline'` | `'stacked'` | Inline puts the value at the end of the term's row. |
| `numeric` (item) | `boolean` | `false` | Wraps the value in `dir="ltr"` tabular mono, for IDs, amounts and dates. |

An empty value (`null`, `undefined`, `''`) renders an em dash.
