import { Card } from '@components/ui';
import { DescriptionList } from '@components/shared';

## Stacked in columns

<Example title="Patient summary">
  <Card className="w-full" title="Patient summary" description="Registered 3 March 2024">
    <Card.Content>
      <DescriptionList
        columns={2}
        items={[
          { term: 'Full name', value: 'Sara Haddad' },
          { term: 'File number', value: 'MRN-20391', numeric: true },
          { term: 'Date of birth', value: '1991-07-14', numeric: true },
          { term: 'Insurer', value: 'Jordan Health Mutual' },
          { term: 'Mobile', value: null },
        ]}
      />
    </Card.Content>
  </Card>
</Example>

An empty value (`null`, `undefined`, `''`) renders an em dash, as for Mobile above.

## Inline

`layout="inline"` puts each value at the end of its term's row; good for narrow side panels.

<Example title="Visit details">
  <div className="border-border w-full max-w-sm rounded-lg border p-4">
    <DescriptionList layout="inline">
      <DescriptionList.Item term="Doctor" value="Dr. Lina Khoury" />
      <DescriptionList.Item term="Room" value="B-204" numeric />
      <DescriptionList.Item term="Duration" value="30 min" numeric />
    </DescriptionList>
  </div>
</Example>

## Accessibility

- Renders a native `<dl>` with `<dt>` and `<dd>`, so screen readers announce each term with its value.

## RTL notes

- Terms align to the start; numeric values are wrapped in `dir="ltr"` so IDs and dates keep their order.
