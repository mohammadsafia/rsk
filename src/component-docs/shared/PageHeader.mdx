## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `title` | `ReactNode` | — | Rendered as the page's `h1`. |
| `description` | `ReactNode` | — | Muted line under the title. |
| `back` | `string \| () => void` | — | A path renders a link; a function renders a button. Labelled `t('common:pageHeader.back')`; the chevron mirrors in RTL. |
| `breadcrumb` | `BreadcrumbLink[]` | — | Rendered with `Breadcrumb` above the title. |
| `PageHeader.Actions` | `div` | — | End-aligned action row that wraps under the title on narrow screens. |
