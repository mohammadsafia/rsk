## Imports

```tsx
import { AppShell, Sidebar, useAppShell } from '@components/shared';
```

## Code

```tsx
<AppShell sidebar={<AppSidebar />}>
  <AppShell.Header>
    <AppShell.MenuButton />
    {/* search, theme, language, user menu */}
  </AppShell.Header>

  <AppShell.Content>
    <Outlet />
  </AppShell.Content>
</AppShell>
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `sidebar` | `ReactNode` | — | Usually a `Sidebar`. Rendered in the desktop rail and the mobile drawer. |
| `storageKey` | `string \| null` | `'rsk:sidebar-collapsed'` | Where the collapsed preference is remembered; `null` turns it off. A blocked storage is ignored. |
| `AppShell.Header` | `header` | — | 56 px bar; gains a raised shadow once the content scrolls. |
| `AppShell.Content` | `main` | — | The scrolling region; the skip link targets it. |
| `AppShell.MenuButton` | — | — | Opens and closes the drawer below `md`. |

`useAppShell()` returns `collapsed`, `setCollapsed`, `toggleCollapsed`, `mobileOpen`, `openMobile` and `closeMobile`.

## Accessibility

- A skip link is the first focusable element and jumps to the content.
- The drawer closes on Escape, on the scrim and when an item is chosen; Escape and the scrim return focus to the menu button.
- The current page carries `aria-current="page"`; collapsed items keep their names and show a tooltip.
