## Imports

```tsx
import { EmptyState } from '@components/shared';
```

## Code

```tsx
<EmptyState kind="first-use" title="No patients yet" description="Patients you register will appear here." />

<EmptyState kind="no-results" />

<EmptyState kind="error" title="Couldn't load visits">
  <EmptyState.Actions>
    <Button variant="outline">Try again</Button>
  </EmptyState.Actions>
</EmptyState>

// Full-page states use a level-1 heading
<EmptyState kind="error" titleAs="h1" />
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `kind` | `'first-use' \| 'no-results' \| 'error'` | `'first-use'` | Picks the icon and the default copy. `error` sets `role="alert"`. |
| `title` / `description` | `ReactNode` | i18n per kind | `common.emptyState.<kind>.*`. |
| `icon` | `ReactNode` | per kind | Replaces the default icon. |
| `size` | `'sm' \| 'md'` | `'md'` | `sm` is used inside tables (`Table.Empty`). |
| `titleAs` | `'h1' \| 'h2' \| 'h3'` | `'h3'` | Heading level of the title. |
| `EmptyState.Actions` | `div` | — | Centered, wrapping row of buttons. |
