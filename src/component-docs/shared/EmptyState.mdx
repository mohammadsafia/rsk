import { Button } from '@components/ui';
import { EmptyState } from '@components/shared';

## Kinds

`kind` picks the icon and the default copy; `title` and `description` override it.

<Example title="First use, no results, error">
  <div className="grid w-full gap-4 md:grid-cols-3">
    <div className="border-border rounded-lg border">
      <EmptyState size="sm" kind="first-use" title="No patients yet" description="Patients you register will appear here." />
    </div>
    <div className="border-border rounded-lg border">
      <EmptyState size="sm" kind="no-results" />
    </div>
    <div className="border-border rounded-lg border">
      <EmptyState size="sm" kind="error" title="Couldn't load visits">
        <EmptyState.Actions>
          <Button size="sm" variant="outline">Try again</Button>
        </EmptyState.Actions>
      </EmptyState>
    </div>
  </div>
</Example>

## With an action

Offer the one thing that fixes the empty state: create the first item, clear the filters, or retry.

<Example title="First use with a primary action">
  <div className="border-border w-full max-w-md rounded-lg border">
    <EmptyState kind="first-use" title="No invoices yet" description="Invoices appear here once a visit is billed.">
      <EmptyState.Actions>
        <Button>Create invoice</Button>
      </EmptyState.Actions>
    </EmptyState>
  </div>
</Example>

For full-page states use `titleAs="h1"` so the page keeps one top-level heading.

`EmptyState.Actions` is a centred, wrapping row of buttons.

## Accessibility

- `kind="error"` sets `role="alert"` so the failure is announced; the other kinds are plain content.
- The icon is decorative; the title carries the message.

## RTL notes

- Content is centred, so nothing needs mirroring; actions wrap in reading order.
