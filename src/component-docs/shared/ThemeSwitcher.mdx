## Toggle

Switches the whole app: the sun and moon icons swap as the theme changes. This site's top bar uses the same button.

<Example title="Theme toggle">
  <ThemeSwitcher />
</Example>

The choice is kept by `ThemeProvider`, which puts `dark` or `light` on `<html>`. See [Theming & tokens](/docs/theming#dark-mode).

## API

ThemeSwitcher takes no props. To build your own control, use the context:

<PropsTable
  rows={[
    { prop: 'useTheme().theme', type: "'dark' | 'light'", description: 'The current theme.' },
    { prop: 'useTheme().setTheme', type: '(theme) => void', description: 'Change and remember the theme.' },
  ]}
/>

## Accessibility

- An `IconButton` whose label says what it will do ("Switch to light theme"), and which also shows as its tooltip.
