## Shapes

`line` for text, `circle` for avatars, `block` for images and cards. Each comes in `sm`, `md` and `lg`.

## Composed

Match the shape of the content that will arrive, so the layout doesn't jump.

<Example title="List row">
  <div className="flex w-full max-w-md items-center gap-3">
    <Skeleton shape="circle" />
    <div className="grid flex-1 gap-2">
      <Skeleton className="w-1/2" />
      <Skeleton size="sm" className="w-3/4" />
    </div>
  </div>
</Example>

`Card` and `DataTable` have their own `loading` states built on Skeleton.

Set widths with `className` (e.g. `w-1/2`) to vary line lengths.

## Accessibility

- Skeletons are `aria-hidden`; mark the loading region with `aria-busy="true"` so screen readers know content is on its way.

## RTL notes

- No direction-specific behaviour; shortened lines align to the start.
