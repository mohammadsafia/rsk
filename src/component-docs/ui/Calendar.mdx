import { useState } from 'react';
import { Calendar } from '@components/ui';

export const RangeDemo = () => {
  const [range, setRange] = useState({ from: new Date(2026, 9, 12), to: new Date(2026, 9, 16) });
  return <Calendar mode="range" defaultMonth={new Date(2026, 9, 1)} selected={range} onSelect={setRange} />;
};

## Look and language

- **Today** has a hairline `border-strong` ring, never a fill.
- **Outside days** use `text-fg-subtle`; **disabled days** are struck through.
- The locale and direction follow the app language, and day numbers always use Western digits.

Every other `DayPicker` prop passes through. For a field with a popover, use `DatePicker` or the form `FormDatePicker`.

## Accessibility

- Days form a grid: arrow keys move by day and week, Page Up/Down by month, Home/End to the week's edges.
- Previous/next buttons and the dropdowns have translated `aria-label`s.

## RTL notes

- In Arabic the grid runs right to left, weekday names are Arabic, and the previous/next chevrons swap sides.
- Day numbers stay Western (0–9).
