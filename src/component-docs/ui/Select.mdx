## Sizes and states

The trigger has Input's heights and invalid state, so it lines up with other fields.

<Example title="Sizes, invalid, disabled">

For long or searchable lists use [Combobox](/docs/components/combobox); in forms, [FormSelect](/docs/components/form-select).

## Accessibility

- Radix renders a `combobox` trigger and a `listbox`; Arrow keys move, typing jumps to a match, Enter selects, Escape closes.
- Label the trigger with a `<label>`, `aria-label`, or the form field.

## RTL notes

- The chevron sits at the end and the check mark at the start of each item, so both swap sides in Arabic.
