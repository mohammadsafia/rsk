import { RadioGroup } from '@components/ui';

## Option cards

Each item is a whole-card radio; the checked card takes the accent border and tint.

<Example title="Plan">
  <RadioGroup aria-label="Plan" defaultValue="clinic" className="max-w-sm">
    <RadioGroup.Item value="solo">
      <span className="flex-1">Solo practice</span>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
    <RadioGroup.Item value="clinic">
      <span className="flex-1">Clinic</span>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
    <RadioGroup.Item value="hospital" disabled>
      <span className="flex-1">Hospital (contact sales)</span>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
  </RadioGroup>
</Example>

## In a row

The root is a grid, so `grid-cols-*` lays the cards out side by side.

<Example title="Two columns">
  <RadioGroup aria-label="Visit type" defaultValue="in-person" className="max-w-md grid-cols-2">
    <RadioGroup.Item value="in-person">
      <span className="flex-1">In person</span>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
    <RadioGroup.Item value="video">
      <span className="flex-1">Video call</span>
      <RadioGroup.Indicator />
    </RadioGroup.Item>
  </RadioGroup>
</Example>

## Dot

`RadioGroup.Dot` is the same circle without behaviour, for custom single-select lists such as table filters.

<Example title="Non-interactive indicator">
  <RadioGroup.Dot checked />
  <RadioGroup.Dot />
</Example>

In forms, use [FormRadioGroup](/docs/components/form-radio-group).

## Accessibility

- Radix renders `role="radiogroup"` with `role="radio"` items; Arrow keys move and select, Tab leaves the group.
- Label the group with `aria-label` or `aria-labelledby`; each card's text is its option name.

## RTL notes

- The label sits at the start and the indicator at the end, so they swap sides in Arabic; Arrow keys follow the reading direction.
