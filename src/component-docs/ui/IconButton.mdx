import { IconButton } from '@components/ui';
import { Copy, Pencil, Trash2 } from 'lucide-react';

## Variants and sizes

Same `variant`, `tone` and `size` as [Button](/docs/components/button); the default variant is `ghost`. Hover to see the tooltip.

<Example title="Variants and sizes">
  <IconButton size="sm" aria-label="Edit">
    <Pencil />
  </IconButton>
  <IconButton variant="outline" aria-label="Duplicate">
    <Copy />
  </IconButton>
  <IconButton variant="solid" tone="danger" size="lg" aria-label="Delete">
    <Trash2 />
  </IconButton>
</Example>

## Rules

- `aria-label` is required by the type and becomes the tooltip text.
- Pass `tooltip={false}` only when the button sits inside another trigger (for example a field's clear control), so tooltips don't stack.
- Use `asChild` with `tooltip={false}` when the icon must render as a non-button element inside another button.

Every other Button prop (`loading`, `disabled`, `asChild`, `onClick`) passes through; `fullWidth` does not apply.

## Accessibility

- The required `aria-label` names the button; the icon inside is decorative.
- The tooltip appears on keyboard focus as well as hover.

## RTL notes

- Mirror directional icons (arrows, chevrons) with `rtl:-scale-x-100`; symmetric icons need nothing.
