## Fallback

When the image is missing or fails to load, the fallback shows initials or an icon.

<Example title="Initials and icon">
  <Avatar>
    <Avatar.Image alt="Omar Khalil" />
    <Avatar.Fallback>OK</Avatar.Fallback>
  </Avatar>
  <Avatar>
    <Avatar.Image alt="Unknown user" />
    <Avatar.Fallback>
      <User aria-hidden="true" className="size-4" />
    </Avatar.Fallback>
  </Avatar>
</Example>

`Avatar.Image` takes `src` and `alt`; `Avatar.Fallback` takes initials or an icon and accepts `delayMs` to avoid a flash while the image loads.

## Accessibility

- Give `Avatar.Image` an `alt` with the person's name. When the name is already next to the avatar, pass `alt=""` so it is not read twice.
- An icon fallback is decorative (`aria-hidden`).

## RTL notes

- No direction-specific behaviour. Write Arabic initials as one or two letters; they render in the Arabic font.
