## Imports

```tsx
import { Avatar } from '@components/ui';
import { User } from 'lucide-react';
```

## Code

```tsx
// With Image
<Avatar>
  <Avatar.Image src="..." alt="User" />
  <Avatar.Fallback>CN</Avatar.Fallback>
</Avatar>

// Custom Size
<Avatar size="lg">
  <Avatar.Image src="..." alt="User" />
  <Avatar.Fallback>LG</Avatar.Fallback>
</Avatar>

// Icon Fallback
<Avatar>
  <Avatar.Image alt="User" />
  <Avatar.Fallback>
    <User />
  </Avatar.Fallback>
</Avatar>
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 24px · 32px · 40px |

The fallback shows initials in `text-fg-muted` on the hover tint.
