## Accessibility

- Radix renders `role="switch"` with `aria-checked`; Space and Enter toggle it.
- Label it with a wrapping `<label>`, `aria-labelledby`, or `aria-label`.

## RTL notes

- The thumb starts at the inline start and slides toward the end, so "on" sits on the left in Arabic.
