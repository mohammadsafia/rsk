import { Collapsible, Button } from '@components/ui';
import { ChevronsUpDown } from 'lucide-react';

## Basic

Use Collapsible for a single show/hide region. For several stacked sections, use [Accordion](/docs/components/accordion).

<Example title="Show more">
  <Collapsible className="w-80 space-y-2">
    <div className="flex items-center justify-between gap-4">
      <h4 className="text-fg text-sm font-semibold">3 attachments</h4>
      <Collapsible.Trigger asChild>
        <Button variant="ghost" size="sm">
          <ChevronsUpDown aria-hidden="true" className="size-4" />
          Show
        </Button>
      </Collapsible.Trigger>
    </div>
    <div className="border-border rounded-md border px-3 py-2 text-sm">lab-results.pdf</div>
    <Collapsible.Content className="space-y-2">
      <div className="border-border rounded-md border px-3 py-2 text-sm">x-ray-front.png</div>
      <div className="border-border rounded-md border px-3 py-2 text-sm">referral-letter.pdf</div>
    </Collapsible.Content>
  </Collapsible>
</Example>

## API

  rows={[

`Collapsible.Trigger` takes `asChild` to use your own button; `Collapsible.Content` animates its height and respects reduced motion.

## Accessibility

- The trigger gets `aria-expanded` and `aria-controls`; Enter and Space toggle it.
- Hidden content is removed from the accessibility tree while closed.

## RTL notes

- No direction-specific behaviour.
