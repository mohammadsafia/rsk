## Basic

The value is end-aligned in tabular mono digits.

<Example title="Number">
  <div className="w-60">
    <FormattedNumber aria-label="Quantity" placeholder="0" />
  </div>
</Example>

## Step buttons

`showStepButtons` adds labelled − / + buttons, disabled at `min` and `max`; ↑ and ↓ step too.

<Example title="Stepper">
  <div className="w-60">
    <FormattedNumber aria-label="Seats" showStepButtons min={0} max={100} stepper={5} defaultValue={10} />
  </div>
</Example>

Note `min` defaults to `0`: pass a negative `min` to allow negative numbers. In forms, use `FormNumber`.

## Accessibility

- A native text input in decimal mode; label it with a `<label>`, `aria-label`, or the form field.
- The step buttons have translated `aria-label`s ("Decrease", "Increase").

## RTL notes

- The control follows the page direction (padding, step buttons, error icon), while the number itself uses plaintext bidi, so `-1,250.50` keeps its order in Arabic.
- Digits stay Western.
