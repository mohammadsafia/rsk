## Pages

The active page is solid; others are ghost buttons.

Tables don't need this: `DataTable.Pagination` builds it from the table state.

## API

<PropsTable
  rows={[
    { prop: 'NavButton · isActive', type: 'boolean', default: 'false', description: 'Marks the current page (solid, aria-current="page").' },
    { prop: 'NavButton', type: 'ButtonProps', description: 'A Button without variant, tone or size; pass onClick or asChild with a Link.' },
    { prop: 'Previous · Next', type: 'IconButtonProps', description: 'aria-label defaults to the translated "Previous page" / "Next page".' },
  ]}
/>

`Pagination` is a `nav`, `List` an `ol`, `Item` an `li`; `Ellipsis` shows a gap and tells screen readers "More pages".

## Accessibility

- `Pagination` is a navigation landmark labelled for screen readers; the active page has `aria-current="page"`.
- Disable `Previous` or `Next` at the ends rather than hiding them, so the layout doesn't shift.

## RTL notes

- The previous/next chevrons rotate in Arabic, so "previous" always points back along the reading direction.
- Page numbers stay Western digits.
