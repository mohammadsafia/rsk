## Horizontal

<Example title="Between sections">
  <div className="w-full max-w-sm space-y-2 text-sm">
    <div>Personal details</div>
    <Divider />
    <div>Insurance</div>
    <Divider variant="dashed" />
    <div>Emergency contact</div>
  </div>
</Example>

## Vertical

A vertical divider stretches to its flex row's height.

<Example title="Inline">
  <div className="flex h-6 items-center gap-3 text-sm">
    <span>Patients</span>
    <Divider orientation="vertical" />
    <span>Visits</span>
    <Divider orientation="vertical" variant="dashed" />
    <span>Invoices</span>
  </div>
</Example>

All other `<hr>` attributes pass through.

## Accessibility

- Renders an `<hr>` (implicit `role="separator"`) with `aria-orientation`. For a purely visual line inside a group, pass `aria-hidden="true"`.

## RTL notes

- No direction-specific behaviour; the dashed vertical line uses the logical `border-s`.
