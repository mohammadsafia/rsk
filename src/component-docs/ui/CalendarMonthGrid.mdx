## Usage

Map your data to cells. `DayCell` renders its own day-number chip; its children fill the events area.

```tsx
<CalendarMonthGrid>
  <CalendarMonthGrid.Weekdays>
    {WEEKDAYS.map((label) => (
      <CalendarMonthGrid.Weekday key={label}>{label}</CalendarMonthGrid.Weekday>
    ))}
  </CalendarMonthGrid.Weekdays>

  <CalendarMonthGrid.Days>
    {days.map((day) => (
      <CalendarMonthGrid.DayCell
        key={day.iso}
        dayNumber={day.number}
        isCurrentMonth={day.isCurrentMonth}
        available={day.hasSlots}
        isToday={day.isToday}
      >
        {day.events.map((event) => (
          <CalendarMonthGrid.EventChip key={event.id} onClick={() => openPopover(event)}>
            <CalendarEvent tone={eventTone(event)}>{formatEventLabel(event)}</CalendarEvent>
          </CalendarMonthGrid.EventChip>
        ))}
      </CalendarMonthGrid.DayCell>
    ))}
  </CalendarMonthGrid.Days>
</CalendarMonthGrid>
```

## Overflow

The primitive does not limit how many events a day shows. Render the first few as `EventChip`s and add your own "+N more" control (for example a link-style `Button` opening a `Popover`) below them.

For a ready-made month view with overflow, navigation and popovers, use [CalendarGrid](/docs/components/calendar-grid).

`CalendarMonthGrid`, `Weekdays`, `Weekday` and `Days` are styled `div`s with no props of their own. The parts share no context, so no provider is needed.

## Accessibility

- Today's cell carries `aria-current="date"`.
- `EventChip` is a native button; give it an `aria-label` with the full event (time, title) when the visible label is shortened.

## RTL notes

- The 7-column grid follows the document direction, so Sunday starts on the right in Arabic.
- Translate the weekday labels you pass in; day numbers stay Western digits.
