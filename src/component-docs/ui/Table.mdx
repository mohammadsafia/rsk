## Numeric columns

`numeric` on `Table.Head` and `Table.Cell` end-aligns the column with mono tabular figures; the value keeps its left-to-right order in Arabic. `data-state="selected"` tints a row.

<Example title="Amounts and a selected row">
  <div className="border-border w-full max-w-md overflow-hidden rounded-lg border">
    <Table>
      <Table.Header>
        <Table.Row>
          <Table.Head>Invoice</Table.Head>
          <Table.Head numeric>Amount</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body>
        <Table.Row>
          <Table.Cell>INV-2026-0142</Table.Cell>
          <Table.Cell numeric>1,240.50</Table.Cell>
        </Table.Row>
        <Table.Row data-state="selected">
          <Table.Cell>INV-2026-0143</Table.Cell>
          <Table.Cell numeric>87.00</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  </div>
</Example>

## Empty and loading

`Table.Empty` renders a full-width message row when `when` is true; `Table.Loader` renders skeleton (or spinner) rows while `isLoading`.

<Example title="Empty row">
  <div className="border-border w-full max-w-md overflow-hidden rounded-lg border">
    <Table>
      <Table.Header>
        <Table.Row>
          <Table.Head>Invoice</Table.Head>
          <Table.Head numeric>Amount</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body>
        <Table.Empty when colSpan={2} title="No invoices yet" description="Invoices appear here once a visit is billed." />
      </Table.Body>
    </Table>

</Example>

## API

<PropsTable
  rows={[
    { prop: 'Head · Cell · numeric', type: 'boolean', default: 'false', description: 'End-aligned, mono tabular figures, LTR-isolated.' },
    { prop: 'Empty · when', type: 'boolean', required: true, description: 'Show the empty row.' },
    { prop: 'Empty · title · description', type: 'ReactNode', description: 'Message; defaults to a translated "No results".' },
    { prop: 'Empty · Loader · colSpan', type: 'number', description: 'Columns to span (required on Loader).' },
    { prop: 'Loader · isLoading · rows', type: 'boolean · number', description: 'Placeholder rows while loading.' },
    { prop: 'Loader · loaderType', type: "'skeleton' | 'spinner'", default: "'skeleton'", description: 'Skeleton rows or a single spinner row.' },
  ]}
/>

`Table`, `Header`, `Body`, `Footer`, `Row`, `Head`, `Cell` and `Caption` render the native table elements.

## Accessibility

- Native table semantics: use `Table.Head` for column headers and add a `Table.Caption` (or `aria-label`) describing the table.
- Don't rely on colour in status cells: badges carry text.

## RTL notes

- Columns run right to left in Arabic and text aligns to the start; numeric columns align to the end.
- Wrap dates and IDs in `dir="ltr"`, as above, so they keep their order.
