## Numeric columns

`numeric` on `Table.Head` and `Table.Cell` end-aligns the column and renders digits in the mono face with tabular figures. The value keeps its left-to-right order in Arabic.

<Table>
  <Table.Header>
    <Table.Row>
      <Table.Head>Invoice</Table.Head>
      <Table.Head numeric>Amount</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>INV-2026-0142</Table.Cell>
      <Table.Cell numeric>1,240.50</Table.Cell>
    </Table.Row>
    <Table.Row data-state="selected">
      <Table.Cell>INV-2026-0143</Table.Cell>
      <Table.Cell numeric>87.00</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>

```tsx
<Table.Head numeric>Amount</Table.Head>
<Table.Cell numeric>1,240.50</Table.Cell>
```
