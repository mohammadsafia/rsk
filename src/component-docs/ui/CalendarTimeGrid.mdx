## Event content

Render event content with `CalendarEvent`: a soft tone tint with a status dot, with text that stays `text-fg` on every tone. Tone is never a coloured side stripe. `past` mutes an event that has ended.

## Week view

Repeat `Header` and `Column` once per day; all columns share one axis.

```tsx
<CalendarTimeGrid>
  <div className="flex shrink-0">
    <CalendarTimeGrid.Spacer />
    {days.map((day) => (
      <CalendarTimeGrid.Header key={day.iso} dayName={day.name} dayNumber={day.number} isToday={day.isToday} />
    ))}
  </div>

  <div className="flex flex-1 overflow-y-auto">
    <CalendarTimeGrid.Axis rows={axisRows} />
    {days.map((day) => (
      <CalendarTimeGrid.Column key={day.iso} rowCount={axisRows.length}>
        {/* cells, event cards, now-line */}
      </CalendarTimeGrid.Column>
    ))}
  </div>
</CalendarTimeGrid>
```

## Axis rows and positions

Build one axis row per grid row; only hour marks carry a label unless `showStepLabels` is on.

```tsx
const axisRows: CalendarTimeGridAxisRow[] = [];
for (let m = 0; m < (endHour - startHour) * 60; m += stepMinutes) {
  const isHourMark = m % 60 === 0;
  axisRows.push({ label: isHourMark ? formatHour(startHour + m / 60) : '', isHourMark });
}
```

Event `top`, `height`, `left` and `width` are percentages of the column, computed from the event's times. For overlapping events, split the column into lanes: `left = lane * (100 / lanes)`, `width = 100 / lanes`.

For a ready-made day and week view, use [CalendarGrid](/docs/components/calendar-grid).

## Accessibility

- `Spacer`, the axis and `NowLine` are decorative (`aria-hidden`); headers and event cards carry the meaning.
- `EventCard` is a native button; give it an `aria-label` with the full time and title when the card is too short to show them.

## RTL notes

- `EventCard`'s `left` is applied as `inset-inline-start`, so lanes mirror in Arabic without changing your maths.
- The axis sits at the start (right in Arabic); time labels you pass should be Western-digit strings.
