import { Card, Button } from '@components/ui';
import { CalendarClock, Users } from 'lucide-react';

## Composition

`Card.Header` holds the title, description and trailing `Card.Actions`; `Card.Content` is the body; `Card.Footer` sits under a hairline.

<Example title="Header, content and footer">
  <Card className="w-full max-w-md">
    <Card.Header>
      <Card.Title>Patients</Card.Title>
      <Card.Description>Seen this week</Card.Description>
      <Card.Actions>
        <Button variant="outline" size="sm">Export</Button>
      </Card.Actions>
    </Card.Header>
    <Card.Content>
      <p className="text-sm">248 visits across 3 clinics.</p>
    </Card.Content>
    <Card.Footer className="flex justify-end gap-2">
      <Button variant="ghost" size="sm">Dismiss</Button>
      <Button size="sm">Open report</Button>
    </Card.Footer>
  </Card>
</Example>

## Header shortcut

`title`, `description`, `icon` and `tooltip` build the header when the card has no `Card.Header` child.

<Example title="Header props">
  <Card className="w-full max-w-md" title="Patients" description="Seen this week" icon={<Users />} tooltip="Counts unique visits">
    <Card.Content>
      <p className="text-sm">248 patients</p>
    </Card.Content>
  </Card>
</Example>

## Tones

A tone tints the whole card; text stays `fg` on every tint.

<Example title="Tones">
  <div className="grid w-full gap-3 sm:grid-cols-3">
    <Card tone="neutral" title="Neutral" />
    <Card tone="accent" title="Accent" />
    <Card tone="info" title="Info" />
    <Card tone="success" title="Success" />
    <Card tone="warning" title="Warning" />
    <Card tone="danger" title="Danger" />
  </div>
</Example>

## Collapsible

`collapsible` adds a toggle to the header; use `defaultOpen` or `open` with `onOpenChange` to control it.

<Example title="Collapsible">
  <Card collapsible className="w-full max-w-md" title="Upcoming visits" icon={<CalendarClock />}>
    <Card.Content>
      <p className="text-sm">Three visits scheduled for tomorrow.</p>
    </Card.Content>
  </Card>
</Example>

## Loading

`loading` replaces the body with skeleton lines while the header stays visible.

<Example title="Loading">
  <Card className="w-full max-w-md" title="Patients" loading>
    <Card.Content>Real content</Card.Content>
  </Card>
</Example>

Parts and their elements: `Card` is an `article`, `Card.Header` a `header`, `Card.Title` an `h3`, `Card.Description` a `p`, `Card.Actions` a `div`, `Card.Content` a `section`, `Card.Footer` a `footer`.

## Accessibility

- The title is an `h3`, so a page using cards should have its `h1` and `h2` above them.
- The collapse toggle and the tooltip trigger are buttons with translated `aria-label`s.

## RTL notes

- `Card.Actions` sits at the end of the header and the icon at the start, so both swap sides in Arabic.
