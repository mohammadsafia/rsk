## Code

```tsx
// Basic Card
<Card>
  <Card.Header>
    <Card.Title>Title</Card.Title>
    <Card.Description>Description</Card.Description>
  </Card.Header>
  <Card.Content>Content</Card.Content>
</Card>

// With header actions
<Card>
  <Card.Header>
    <Card.Title>Patients</Card.Title>
    <Card.Description>Seen this week</Card.Description>
    <Card.Actions>
      <Button variant="outline" size="sm">Export</Button>

// With Footer
<Card>
  <Card.Header>
    <Card.Title>Title</Card.Title>
  </Card.Header>
  <Card.Content>Content</Card.Content>
  <Card.Footer>Footer content</Card.Footer>
</Card>
```

## Parts

| Part | Element | Notes |
|---|---|---|
| `Card` | `article` | `bg-surface`, hairline border, 10px radius, no resting shadow |
| `Card.Header` | `header` | Grid; gains a trailing column when it holds `Card.Actions` |
| `Card.Title` | `h3` | `text-md` semibold |
| `Card.Description` | `p` | `text-fg-muted` |
| `Card.Actions` | `div` | Header trailing slot |
| `Card.Content` | `section` | Body |
| `Card.Footer` | `footer` | Top hairline, inline actions |

## Tone

A tone tints the whole card; text stays `fg` on every tint.

<div className="grid gap-3 sm:grid-cols-3">
  <Card tone="neutral" title="Neutral" />
  <Card tone="accent" title="Accent" />
  <Card tone="info" title="Info" />
  <Card tone="success" title="Success" />
  <Card tone="warning" title="Warning" />
  <Card tone="danger" title="Danger" />
</div>

## Header shortcut

`title`, `description`, `icon` and `tooltip` build the header when there is no `Card.Header` child.

<Card title="Patients" description="Seen this week" icon={<Users />} tooltip="Counts unique visits">
  <Card.Content>
    <p className="text-sm">248 patients</p>
  </Card.Content>
</Card>

## Collapsible

<Card collapsible title="Upcoming visits" icon={<CalendarClock />}>
  <Card.Content>
    <p className="text-sm">Three visits scheduled for tomorrow.</p>
  </Card.Content>
</Card>

```tsx
<Card collapsible defaultOpen={false}>
  <Card.Header>
    <Card.Title>Billable lines</Card.Title>
    <Card.Actions>
      <Button size="sm" variant="outline">Add line</Button>
    </Card.Actions>
  </Card.Header>
  <Card.Content>…</Card.Content>
</Card>
```

A collapsed card unmounts its body, so its controls leave the tab order. Use `open` / `onOpenChange` to control it.

## API (additions)

| Prop | Type | Default | Notes |
|---|---|---|---|
| `tone` | `neutral` · `accent` · `info` · `success` · `warning` · `danger` | `neutral` | Whole-card tint |
| `title` / `description` / `icon` / `tooltip` | `ReactNode` | — | Header shortcut |
| `collapsible` | `boolean` | `false` | Adds the toggle in the header |
| `open` / `defaultOpen` / `onOpenChange` | — | `defaultOpen` `true` | Collapsible state |
| `loading` | `boolean` | `false` | Body becomes skeleton lines |
