import { ScrollArea } from '@components/ui';

## Vertical

Give the area a fixed or flex-constrained height, and always render `ScrollArea.Bar`.

<Example title="List">
  <ScrollArea className="border-border h-48 w-72 rounded-md border">
    <div className="grid gap-2 p-3">
      {Array.from({ length: 20 }, (_, index) => (
        <div key={index} className="text-sm">
          Patient {index + 1}
        </div>
      ))}
    </div>
    <ScrollArea.Bar />
  </ScrollArea>
</Example>

<Callout tone="warning" title="The bar is what makes it scroll">
  Radix only enables overflow on the viewport while a scrollbar is mounted. A ScrollArea without `ScrollArea.Bar` clips its content instead of scrolling.
</Callout>

## Horizontal

<Example title="Wide row">
  <ScrollArea className="border-border w-72 rounded-md border" orientation="horizontal">
    <div className="flex w-max gap-2 p-3">
      {Array.from({ length: 12 }, (_, index) => (
        <div key={index} className="bg-surface-sunken text-fg-muted rounded-md px-3 py-6 text-sm">
          Slot {index + 1}
        </div>
      ))}
    </div>
    <ScrollArea.Bar orientation="horizontal" />
  </ScrollArea>
</Example>

## Accessibility

- The viewport is a native scroll container, so wheel, touch, keyboard and screen readers work as usual.
- If the region holds important content, make it focusable (`tabIndex={0}`) and label it so keyboard users can scroll it.

## RTL notes

- The vertical bar sits at the inline end (left in Arabic); horizontal scrolling starts from the right.
