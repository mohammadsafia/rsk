## Imports

```tsx
import { Tabs } from '@components/ui';
```

## Code

```tsx
// underline (default) · underline fullWidth · contained · contained fullWidth
<Tabs defaultValue="account">
  <Tabs.List variant="contained" fullWidth>...</Tabs.List>
  <Tabs.List variant="contained">...</Tabs.List>
  <Tabs.List fullWidth>...</Tabs.List>
  <Tabs.List>...</Tabs.List>
</Tabs>
```

## API

| Prop (`Tabs.List`) | Type | Default | Notes |
|---|---|---|---|
| `variant` | `'underline' \| 'contained'` | `'underline'` | Underline: 2px accent bar under the active tab. Contained: sunken track, active tab on the surface. |
| `fullWidth` | `boolean` | `false` | Triggers share the full width. |
