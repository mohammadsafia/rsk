## Single

`type="single"` behaves like a segmented control: one item is on at a time.

<Example title="Outline and ghost">
  <div className="grid gap-3">
    <ToggleGroup type="single" defaultValue="week" aria-label="Range">
      <ToggleGroup.Item value="day">Day</ToggleGroup.Item>
      <ToggleGroup.Item value="week">Week</ToggleGroup.Item>
      <ToggleGroup.Item value="month">Month</ToggleGroup.Item>
    </ToggleGroup>
    <ToggleGroup type="single" variant="ghost" defaultValue="week" aria-label="Range">
      <ToggleGroup.Item value="day">Day</ToggleGroup.Item>
      <ToggleGroup.Item value="week">Week</ToggleGroup.Item>
      <ToggleGroup.Item value="month">Month</ToggleGroup.Item>
    </ToggleGroup>
  </div>
</Example>

## Multiple

`type="multiple"` lets any number of items be on. Icon-only items need an `aria-label`.

<Example title="Text formatting">
  <ToggleGroup type="multiple" defaultValue={['bold']} aria-label="Formatting">
    <ToggleGroup.Item value="bold" aria-label="Bold">
      <Bold className="size-4" />
    </ToggleGroup.Item>
    <ToggleGroup.Item value="italic" aria-label="Italic">
      <Italic className="size-4" />
    </ToggleGroup.Item>
    <ToggleGroup.Item value="underline" aria-label="Underline">
      <Underline className="size-4" />
    </ToggleGroup.Item>
  </ToggleGroup>
</Example>

`variant` and `size` set on the group apply to every item; an item can override them.

## Accessibility

- Items are buttons with `aria-pressed` (multiple) or `role="radio"` and `aria-checked` (single); Arrow keys move between them.
- Label the group with `aria-label`, and icon-only items individually.

## RTL notes

- Items run right to left in Arabic and Arrow keys follow the reading direction.
