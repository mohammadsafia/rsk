## Overlay

`overlay` covers the nearest positioned ancestor with a translucent scrim. Add `fixed` to cover the viewport.

<Example title="Container overlay">
  <div className="border-border relative h-32 w-full max-w-md rounded-lg border p-4">
    <p className="text-fg-muted text-sm">Visit summary is refreshing…</p>
    <Spinner overlay label="Refreshing visit summary" />
  </div>
</Example>

## Accessibility

- Renders `role="status"` with the label as text, so screen readers announce it politely; the icon is `aria-hidden`.
- Rotation stops under `prefers-reduced-motion`.

## RTL notes

- No direction-specific behaviour.
