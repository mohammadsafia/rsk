## Imports

```tsx
import { Spinner } from '@components/ui';
```

## Code

```tsx
<Spinner size="sm" />
<Spinner />
<Spinner size="lg" />

// Covers the nearest positioned parent
<div className="relative h-32 rounded-lg border">
  <Spinner overlay label="Refreshing visit summary" />
</div>

// Route-level fallback: covers the viewport
<Suspense fallback={<Spinner overlay fixed size="lg" />}>…</Suspense>
```

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 16, 24 or 32 px. |
| `label` | `string` | `t('common:loading')` | Screen-reader text inside the `role="status"` region. |
| `overlay` | `boolean` | `false` | Absolutely covers the nearest positioned ancestor with a translucent canvas scrim. |
| `fixed` | `boolean` | `false` | With `overlay`, covers the viewport instead. |

Rotation stops under `prefers-reduced-motion`.
