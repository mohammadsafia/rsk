## Imports

```tsx
import { Alert } from '@components/ui';
import { InfoIcon } from 'lucide-react';
```

## Variant and tone

`variant` is the treatment, `tone` is the meaning. Danger alerts use `role="alert"` (announced immediately); every other tone uses `role="status"`.

| Prop | Values | Use |
|---|---|---|
| `variant` | `soft` (default) | Tinted background with a hairline tone border |
| | `outline` | Surface background, neutral hairline; tone only on the icon — no side stripe |
| `tone` | `neutral` (default), `info`, `success`, `warning`, `danger` | The message's meaning |

## Code

```tsx

<Alert>
  <InfoIcon />
  <Alert.Title>Default</Alert.Title>

<Alert tone="success">

<Alert tone="danger">

  <Alert.Title>Subtle Error</Alert.Title>

</Alert>
```
