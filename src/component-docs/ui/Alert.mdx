import { Alert } from '@components/ui';
import { CircleAlert, CircleCheck, Info, TriangleAlert } from 'lucide-react';

## Tones

`tone` is the meaning of the message. The soft variant (default) tints the background.

<Example title="Soft tones">
  <div className="grid w-full max-w-md gap-2">
    <Alert>
      <Info />
      <Alert.Title>Sync scheduled</Alert.Title>
      <Alert.Description>Records sync every night at 02:00.</Alert.Description>
    </Alert>
    <Alert tone="info">
      <Info />
      <Alert.Title>New lab results</Alert.Title>
      <Alert.Description>3 results arrived since your last visit.</Alert.Description>
    </Alert>
    <Alert tone="success">
      <CircleCheck />
      <Alert.Title>Invoice paid</Alert.Title>
      <Alert.Description>The payment was received.</Alert.Description>
    </Alert>
    <Alert tone="warning">
      <TriangleAlert />
      <Alert.Title>Licence expires soon</Alert.Title>
      <Alert.Description>Renew within 14 days to avoid interruption.</Alert.Description>
    </Alert>
    <Alert tone="danger">
      <CircleAlert />
      <Alert.Title>Payment failed</Alert.Title>
      <Alert.Description>The card was declined. Try another method.</Alert.Description>
    </Alert>
  </div>
</Example>

## Outline

`outline` keeps the surface background and a neutral hairline; the tone shows only on the icon. There is no coloured side stripe.

<Example title="Outline">
  <div className="grid w-full max-w-md gap-2">
    <Alert variant="outline" tone="info">
      <Info />
      <Alert.Title>Maintenance window</Alert.Title>
      <Alert.Description>Sunday 01:00–03:00.</Alert.Description>
    </Alert>
    <Alert variant="outline" tone="danger">
      <CircleAlert />
      <Alert.Title>Upload failed</Alert.Title>
      <Alert.Description>The file is larger than 10 MB.</Alert.Description>
    </Alert>
  </div>
</Example>

## API

<PropsTable
  rows={[
    { prop: 'variant', type: "'soft' | 'outline'", default: "'soft'", description: 'Tinted background, or surface with a neutral hairline.' },
    { prop: 'tone', type: "'neutral' | 'info' | 'success' | 'warning' | 'danger'", default: "'neutral'", description: 'The meaning of the message.' },
  ]}
/>

Put an optional icon first, then `Alert.Title` and `Alert.Description`; the layout aligns them in a grid.

## Accessibility

- `tone="danger"` renders `role="alert"` and is announced immediately; every other tone renders `role="status"` (polite).
- Icons are decorative; the title carries the meaning, so never rely on colour alone.

## RTL notes

- The icon sits at the start and text aligns to the start; no icon needs mirroring.
