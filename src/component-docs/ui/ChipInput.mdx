export const CheckedDemo = () => {
  const [domains, setDomains] = useState(['example.com', 'not a domain', 'taken.org']);

  return (
    <ChipInput
      aria-label="Allowed domains"
      listLabel="Allowed domains"
      value={domains}
      onChange={setDomains}
      validate={(item) => /^[\w-]+(\.[\w-]+)+$/.test(item)}
      flagged={{ 'taken.org': 'Already used by another workspace' }}
      invalidLabel="(not a domain)"
      className="w-96"
    />
  );
};

## Tags

Type and press Enter, or a comma or space; paste a list to add it all at once. An item already there (in any case) is skipped, Backspace in the empty field removes the last chip, and leaving the field keeps what was typed. The field grows with its chips.

## Checked items

`validate` marks an item that isn't valid; `flagged` marks items from outside, such as ones your server refused, with the reason. Both are marked in words for screen readers as well as in colour.

## Accessibility

- The input keeps the focus; chips are a list, each with a remove button named after its item.
- An item that isn't valid or was refused says so in text (its reason), not only in red.

## RTL notes

- Chips flow from the start of the field and wrap; each item is isolated (`<bdi>`), so a Latin address reads correctly inside Arabic text.
