import { Button, Dialog, Input } from '@components/ui';

## Basic

`Dialog.Content` takes the `title` and an optional `description`; actions go in `Dialog.Footer`.

<Example title="Edit form">
  <Dialog>
    <Dialog.Trigger asChild>
      <Button variant="outline">Edit profile</Button>
    </Dialog.Trigger>
    <Dialog.Content title="Edit profile" description="Changes are saved when you press Save.">
      <Input aria-label="Name" defaultValue="Layla Haddad" />
      <Dialog.Footer>
        <Dialog.Close asChild>
          <Button variant="outline">Cancel</Button>
        </Dialog.Close>
        <Button tone="accent">Save</Button>
      </Dialog.Footer>
    </Dialog.Content>
  </Dialog>
</Example>

## Not dismissible

`dismissible={false}` removes the close button and ignores Escape and outside clicks, so the user must choose an action.

<Example title="Required step">
  <Dialog>
    <Dialog.Trigger asChild>
      <Button variant="outline">Finish setup</Button>
    </Dialog.Trigger>
    <Dialog.Content title="Finish this step" description="Escape and outside clicks are ignored." dismissible={false}>
      <Dialog.Footer>
        <Dialog.Close asChild>
          <Button>Done</Button>
        </Dialog.Close>
      </Dialog.Footer>
    </Dialog.Content>
  </Dialog>
</Example>

For "Are you sure?" prompts, use [ConfirmDialog](/docs/components/confirm-dialog).

## Accessibility

- Radix sets `role="dialog"`, `aria-modal`, and links the title and description; focus moves in, is trapped, and returns to the trigger on close.
- Escape closes a dismissible dialog. Put the primary action last in the footer.

## RTL notes

- The close button sits at the end of the header and footer actions align to the end, so both move left in Arabic.
