## States

<Example title="Unchecked, checked, indeterminate, disabled, invalid">
  <Checkbox aria-label="Unchecked" />
  <Checkbox aria-label="Checked" defaultChecked />
  <Checkbox aria-label="Indeterminate" checked="indeterminate" />

  <Checkbox aria-label="Invalid" invalid />

## With a label

Wrap the checkbox and its text in a `<label>` so clicking the text toggles it.

<Example title="Labelled">
  <label className="text-fg flex items-center gap-2 text-sm">
    <Checkbox defaultChecked />
    Email me when a report is ready
  </label>
</Example>

In forms, use [FormCheckbox](/docs/components/form-checkbox), which adds the label, description and error message.

## Accessibility

- Radix renders a `button` with `role="checkbox"` and `aria-checked` (`mixed` when indeterminate); Space toggles it.
- Every checkbox needs a label: a wrapping `<label>`, `aria-labelledby`, or `aria-label` when there is no visible text.

## RTL notes

- No direction-specific behaviour; in a label the box sits at the start.
