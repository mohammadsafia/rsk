## Variants

`variant` is visual weight: one `solid` button per view for the primary action, `outline` for secondary actions, `ghost` for low-emphasis and toolbar actions, `link` for inline navigation.

<Example title="Variants">
  <Button>Save</Button>
  <Button variant="outline">Export</Button>
  <Button variant="ghost">Cancel</Button>
  <Button variant="link">View chart</Button>
</Example>

## Tones

`tone` is meaning: `neutral` for ordinary actions, `accent` for the Oxblood brand action, `danger` for destructive ones.

<Example title="Tones across variants">
  <div className="grid gap-3">
    <div className="flex flex-wrap items-center gap-2">
      <Button>Save</Button>
      <Button tone="accent">Approve</Button>
      <Button tone="danger">Delete</Button>
    </div>
    <div className="flex flex-wrap items-center gap-2">
      <Button variant="outline">Export</Button>
      <Button variant="outline" tone="accent">Assign</Button>
      <Button variant="outline" tone="danger">Revoke</Button>
    </div>
    <div className="flex flex-wrap items-center gap-2">
      <Button variant="ghost">Cancel</Button>
      <Button variant="ghost" tone="accent">Details</Button>
      <Button variant="ghost" tone="danger">Remove</Button>
    </div>
  </div>
</Example>

## States

`loading` shows a spinner and blocks clicks while keeping the label; `disabled` dims the button.

<Example title="Loading and disabled">
  <Button loading>Saving</Button>
  <Button disabled>Disabled</Button>
  <Button fullWidth variant="outline">Full width</Button>
</Example>

## As a link

`asChild` passes the button styling to its child, such as a router `Link`.

<Example title="Router link">
  <Button asChild variant="outline">
    <Link to="/members">Members</Link>
  </Button>
</Example>

## Choosing variant and tone

- **One solid button per view.** Everything else is `outline`, `ghost` or `link`.
- **Success-coloured buttons do not exist.** A successful action is just the primary action.
- **Icon-only actions use `IconButton`**, which requires an `aria-label` and shows it as a tooltip.
- Use `className` only for layout (width, margin, position), never for colour.

All native `<button>` attributes pass through. The default `type` is the browser's (`submit` inside a form), so set `type="button"` for buttons that should not submit.

## Accessibility

- A native `<button>`: Enter and Space activate it, and the focus ring uses the shared `focus-ring` token.
- While `loading`, the button reports `aria-busy` and its label is visually hidden (kept for width), so screen readers announce the spinner's "Loading" instead of the label. Keep the surrounding context clear about which action is running.

## RTL notes

- Icons placed before the label sit at the start; mirror directional ones (arrows, chevrons) with `rtl:-scale-x-100`.
