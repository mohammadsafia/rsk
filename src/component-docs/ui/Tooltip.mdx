## Imports

```tsx
import { Tooltip } from '@components/ui';
```

## Code

```tsx
<Tooltip content="Helpful hint">
  <Button variant="outline">Hover me</Button>
</Tooltip>

<Tooltip content="Shown below" side="bottom" align="start">
  <Button variant="outline">Bottom start</Button>
</Tooltip>
```

`IconButton` shows its `aria-label` as a tooltip automatically. A single `Tooltip.Provider` is mounted at the app root, so you never add one yourself.

## API

| Prop | Type | Default | Notes |
|---|---|---|---|
| `content` | `ReactNode` | — | Tooltip text. Empty content renders only the trigger. |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` | Preferred side. |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Alignment against the trigger. |
| `delayDuration` | `number` | provider (300ms) | Hover delay before opening. |
| `disabled` | `boolean` | `false` | Render the trigger with no tooltip. |
| `className` | `string` | — | Applied to the bubble. |
