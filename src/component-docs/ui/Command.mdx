## Inline list

Type to filter. Items are grouped, and `Command.Shortcut` shows a mono key hint at the end.

## Palette dialog

`Command.Dialog` puts the list in a dialog, for a ⌘K-style palette. Pass `filter` to change ranking (this site's search uses it to ignore Arabic diacritics).

## Accessibility

- The input controls a `listbox`; Arrow keys move the active option and Enter selects it.
- `Command.Dialog` requires a `title` and traps focus like any dialog.

## RTL notes

- Icons sit at the start and shortcuts at the end (`ms-auto`), so they swap sides in Arabic.
