import { Badge } from '@components/ui';

## Dot

The default variant: a small tone dot next to neutral text. Use it in dense tables and lists.

<Example title="Dot">
  <Badge>Draft</Badge>
  <Badge tone="accent">Assigned</Badge>
  <Badge tone="success">Active</Badge>
  <Badge tone="warning">Pending</Badge>
  <Badge tone="danger">Overdue</Badge>
  <Badge tone="info">Referred</Badge>
</Example>

## Soft

A tinted background for when the status should stand out.

<Example title="Soft">
  <Badge variant="soft">Draft</Badge>
  <Badge variant="soft" tone="accent">Assigned</Badge>
  <Badge variant="soft" tone="success">Active</Badge>
  <Badge variant="soft" tone="warning">Pending</Badge>
  <Badge variant="soft" tone="danger">Overdue</Badge>
  <Badge variant="soft" tone="info">Referred</Badge>
</Example>

## Sizes

<Example title="Sizes">
  <Badge variant="soft" tone="success" size="sm">Active</Badge>
  <Badge variant="soft" tone="success">Active</Badge>
</Example>

Badges are never interactive. For removable or clickable labels use [Tag](/docs/components/tag).

## Accessibility

- Renders a plain `<span>`; the dot is `aria-hidden`, so the text must say the status (don't rely on colour).

## RTL notes

- The dot sits at the start of the label, so it moves to the right in Arabic automatically.
