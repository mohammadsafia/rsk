## Field family

Every field shares Input's shape: the same heights, border, focus ring and invalid state, so they line up in a row.

<Example title="Fields side by side">
  <div className="grid w-full gap-3 sm:grid-cols-2">
    <Input aria-label="Name" placeholder="Layla Haddad" />
    <Select>
      <Select.Trigger aria-label="Role">
        <Select.Value placeholder="Role" />
      </Select.Trigger>
      <Select.Content>
        <Select.Item value="admin">Admin</Select.Item>
        <Select.Item value="editor">Editor</Select.Item>
      </Select.Content>
    </Select>
    <TimePicker name="time" placeholder="Time" />
    <FormattedNumber aria-label="Amount" showStepButtons />
  </div>
</Example>

In forms, use [FormInput](/docs/components/form-input), which adds the label, description and error message.

Every native `<input>` attribute passes through (`type`, `value`, `onChange`, `disabled`, …).

## Accessibility

- A native input: give it a `<label htmlFor>`, `aria-label`, or use the form field, which wires the label and the error's `aria-describedby`.
- A placeholder is not a label.

## RTL notes

- The input uses `dir="auto"`, so typed text takes the direction of its first strong character: Arabic reads right to left, an email address left to right.
