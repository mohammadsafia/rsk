## Stacked

`stacked` piles the series so the top edge reads as the total.

<Example title="Visits by channel">
  <AreaChart
    className="w-full"
    aria-label="Monthly visits by channel; video visits doubled since May"
    data={VISITS}
    series={[{ key: 'inPerson', label: 'In person' }, { key: 'video', label: 'Video' }]}
    x={{ key: 'month' }}
    stacked
  />
</Example>

## Single series

<Example title="Video visits">
  <AreaChart className="w-full" aria-label="Video visits per month" data={VISITS} series={[{ key: 'video', label: 'Video', tone: 'info' }]} x={{ key: 'month' }} />
</Example>

## Accessibility

- A `figure` named by `aria-label`; the legend's buttons toggle series with `aria-pressed`, and the last visible series can't be hidden.
- "View as table" swaps the chart for a table of the same values; arrow keys move between points (recharts accessibility layer).
- Animation is off under `prefers-reduced-motion`.

## RTL notes

- In Arabic the time axis runs right to left and the value axis sits on the right; values stay LTR-isolated with Western digits.
