## Accessibility

- A `figure` named by `aria-label`; legend buttons toggle slices with `aria-pressed`, and the last slice can't be hidden.
- "View as table" lists each slice with its value; the centre text is decorative and repeated in the label.

## RTL notes

- Slices start at the top and the legend follows the reading direction; the centre value is LTR-isolated.
